# Release Note: GDA-291

## Geo ingestion for SEO Pricemap

This release updates Geo ingestion to support the Street and Hono scope required by SEO Pricemap.

### What changed

- Replaced the daily Geo batch ingestion path with an event-driven flow for live updates.
- Added Geo replay support so the materialized view can be rebuilt from a full Geo snapshot when needed.
- Added support for reading Geo data lake Parquet files and loading them through DuckDB into PostgreSQL before updating DynamoDB.
- Optimized SQL and Lambda processing to handle the expected growth from approximately 70,000 to 40 million records.

### Architecture remarks

The solution consumes Geo data through Parquet exports rather than connecting directly to the data lake. Parquet provides a structured, efficient and versionable exchange format for bulk loading and replay while keeping the data lake and the consumer independently managed.

This separation avoids coupling the service to the data lake's internal implementation and limits access to a controlled export boundary. It also reduces the blast radius of changes, supports independent ownership and deployment, and makes full Geo replays reproducible from a specific snapshot.

### Benefits

- Faster time to market through near-real-time updates in live environments.
- More reliable processing at large data volumes.
- Lower operating cost by reducing reliance on a full daily batch.
